# Страницы и роутинг живут на фронтенде

Бекенд проекта — Rails в режиме API и отдаёт только JSON; интерфейс — отдельное SPA на Vite + React. Решено: все страницы, включая главную, рендерит фронтенд, роутинг — react-router, бекенд HTML не отдаёт. Альтернатива — перевести Rails на full-stack и отдавать страницы из него — отвергнута: стек зафиксирован как API + SPA, а граница «фронтенд владеет интерфейсом, бекенд владеет данными» оставляет каждое приложение простым и заменяемым по отдельности.
