# Тесты фронтенда — Vitest + React Testing Library

Фронтенду нужны тесты, но стек для них не был выбран. Решено: компонентные тесты пишем на Vitest + React Testing Library (окружение jsdom) и гоняем их в CI; e2e (Playwright) не ставим. Vitest переиспользует уже существующий Vite-конфиг, а RTL проверяет поведение через доступность, а не внутренности компонентов; e2e — оверкилл для текущего объёма интерфейса, добавим при реальной необходимости.
